# Lab 3 - Architectures and Their Costs

This is a VS Code-ready implementation of the attached Lab 3 sheet. It uses the specified MLP, CNN and patch-attention architectures without changing their layer sizes. Use Python 3.10 or newer.

## 1. Open the project in VS Code

1. Extract/open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Create and activate a virtual environment in PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

## 2. Install packages

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

If PyTorch installation fails on your computer, install the matching PyTorch and torchvision builds using the official PyTorch installation selector, then install the remaining packages from `requirements.txt`.

## 3. Run the lab

```powershell
python main.py
```

The first run downloads Fashion-MNIST, so an internet connection is required. The script automatically uses CUDA when PyTorch reports it as available; otherwise, it runs on CPU. Five epochs are run for each of the three models as required by the sheet. CPU training can take a while.

## 4. Files generated by the run

- `report.md` - report populated with measurements from your run.
- `outputs/results.csv` - model parameters, accuracy, THOP counts and latency.
- `outputs/training_history.csv` - per-epoch training and validation metrics.
- `outputs/model_summaries.txt` - `torchinfo.summary` output for all models.
- `outputs/accuracy_vs_parameters.png` - accuracy vs parameter count.
- `outputs/accuracy_vs_latency_batch1.png` - accuracy vs median batch-1 latency.
- `outputs/accuracy_vs_latency_batch128.png` - accuracy vs median batch-128 latency.
- `outputs/*_state_dict.pth` - trained model weights.

The latency protocol includes 10 warm-up forwards, then calculates the median of 100 timed runs for batch 1 and 20 timed runs for batch 128. Each timing is the whole forward pass for the given batch.

## Important note about the assignment specification

The sheet asks for models targeting 100k-150k parameters, but its exact architecture definitions do not satisfy that target simultaneously. With standard PyTorch layers and biases, the defined models have:

- MLP: **235,146** parameters.
- CNN: **20,490** parameters.
- Attention: **70,794** parameters.

To follow the explicit architecture instructions, this project implements the listed layer dimensions exactly and documents the mismatch in `report.md` rather than changing the models.

## Before submitting

Run the script, inspect `report.md`, the generated CSV files and plots, then commit the code and measured outputs required by your instructor. Results are intentionally measured on your computer; this project does not invent training accuracy or latency values in advance.

## 5. Commit the completed lab

After `python main.py` finishes and you have inspected the generated report and plots, run these commands from the project folder:

```powershell
git init
git add .
git commit -m "Complete Lab 3 architecture cost analysis"
```

The `.gitignore` excludes the downloaded dataset, virtual environment, Python cache and saved model-weight files. The report, source code, CSV measurements, model summaries and plots can be committed.
